
# Amayzon

**Amayzon** is a modern e-commerce web application built to simulate the core functionality of a real-world online marketplace. Designed with scalability, performance, and user experience in mind, Amayzon serves as a full-stack project that showcases end-to-end development from frontend interface to backend infrastructure and database design.

---

## ✨ Features

- 🔐 **Authentication** – Secure login and registration system using JWT
- 🛒 **Product Management** – Admin panel for creating, editing, and removing products
- 🧾 **Cart & Orders** – Dynamic cart system and checkout flow
- 💳 **Payments** – Integration with Stripe or PayPal for seamless transactions
- 🔍 **Search & Filter** – Product filtering by category, price, and search query
- ⭐ **Reviews** – Customer product reviews and ratings
- 📱 **Responsive UI** – Mobile-first layout using modern design principles

---

## 🛠 Tech Stack

- **Frontend:** React.js, Redux, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (with Mongoose)
- **Authentication:** JSON Web Tokens (JWT)
- **Payments:** Stripe API
- **Deployment:** Docker, AWS EC2, Nginx
